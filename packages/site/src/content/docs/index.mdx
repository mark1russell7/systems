## One question, three answers

Linux 6.6 has default settings for each TCP timer. With these settings, the client learns of a black hole or a frozen peer at these times. The model of the lab computes each time from the rules of the kernel.

<Answers />

The lab below computes these times for your settings. Select a harness cell to see the runs that the harness measured. Change a setting to see the new prediction.
